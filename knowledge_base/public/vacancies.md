## 1. Senior Python Developer (команда Core)

**Формат:** удалёнка / гибрид (Москва)
**Занятость:** полная

### Задачи
- Разработка и поддержка микросервисов на FastAPI
- Проектирование высоконагруженных очередей на Kafka
- Участие в code review и архитектурных обсуждениях
- Менторство junior/middle разработчиков команды

### Требования
- 4+ лет коммерческого опыта на Python
- Глубокое понимание async, concurrency, профилирования
- Опыт работы с PostgreSQL и Redis в продакшне
- Знание Kafka или аналогичных брокеров сообщений
- Умение писать понятный, тестируемый код

### Будет плюсом
- Опыт в логистике или supply chain
- Знание Go
- Опыт работы в командах 10+ человек

**Вознаграждение:** конкурентное, обсуждается индивидуально
