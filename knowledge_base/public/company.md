# Meridian Software — О компании

## Кто мы

Meridian Software — российская продуктовая компания, разрабатывающая B2B SaaS-платформу для управления логистическими операциями. Наш продукт помогает транспортным и торговым компаниям автоматизировать маршрутизацию, отслеживание грузов и аналитику цепочек поставок.

Основана в 2017 году. Штаб-квартира — Москва, Пресненская набережная 6с2. Сотрудники работают как в офисе, так и полностью удалённо по всей России.

## Масштаб

- 150+ сотрудников
- 400+ клиентов в сегментах e-commerce, ритейл и FMCG
- Присутствие в 7 федеральных округах России

## Технологический стек

**Backend:** Python (FastAPI, Celery), Go (микросервисы реального времени)
**Frontend:** React, TypeScript
**Инфраструктура:** Kubernetes (EKS), PostgreSQL, Redis, Kafka
**Аналитика:** ClickHouse, dbt, Airflow

## Команды

- **Platform** — инфраструктура, надёжность, DevOps
- **Core** — основная логистическая платформа
- **Intelligence** — ML-модели для маршрутизации и прогнозирования
- **Growth** — интеграции с партнёрами, API, marketplace

## Ценности компании

**Честность.** Говорим прямо, признаём ошибки, не политикуем.
**Скорость с качеством.** Быстро, но без технического долга ради дедлайна.
**Автономность.** Инженеры принимают решения там, где понимают лучше других.
**Клиентоцентричность.** Каждая задача — ответ на реальную проблему клиента.
